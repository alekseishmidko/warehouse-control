# 0007. Документация модулей и файлов, DRY и shared

- Дата: 2026-10-17
- Статус: Accepted

## Контекст

Пользователь требует документации для разработчиков и менеджеров, всех backend-модулей
и файлов, а также устранения дублирования и выделения общей вспомогательной логики.

## Решение

README каждого модуля содержит бизнес- и технический разделы. Исходники имеют
file-level docs, публичные символы — контракт. Конфигурации без комментариев
описываются в README и каталоге; generated artifacts — через генератор.
Документация обновляется вместе с кодом. Общая техническая логика — в shared,
адаптеры — в infrastructure, бизнес-правила остаются у владельцев модулей.

## Альтернативы

Одной архитектуры мало для объяснения файлов и менеджерских сценариев.
Комментарии каждой строки быстро устаревают. Вынос всей логики в shared разрушает
границы модулей; синтаксическое сходство не доказывает одинаковый контракт.

## Последствия и проверка

Растёт объём сопровождения. Обязательны каталог файлов, README модулей,
проверка дублирования и documentation review. CI doc gates пока не внедрены.
См. [стандарт](../documentation-standard.md) и [shared](../shared.md).
