# 0006. Наблюдаемость и воспроизводимая поставка

- Дата: 2026-10-17
- Статус: Accepted

## Контекст

Сбои и повторы фоновой обработки должны быть видны и воспроизводимы.

## Решение

Pino + OpenTelemetry, Prometheus/Grafana, Loki/Tempo.
Testcontainers для реальной инфраструктуры, k6 для нагрузки.
Целевой CI/CD: GitHub Actions, GHCR, Argo CD; точное подключение после
подтверждения Git hosting и окружения. Секреты не хранятся открыто в Git.

## Альтернативы

Только stdout не объясняет путь события через процессы.
Ручной deploy не обеспечивает воспроизводимость конфигурации.
Полный observability stack сразу перегружает первый вертикальный сценарий.

## Последствия и проверка

Вводим по этапам: сначала structured logs/correlation, затем метрики/traces,
потом GitOps. Ограничиваем cardinality и объём хранения.
Нужны alert/recovery drills, проверка rollback и contract gates. Этапы 4 и 6.
