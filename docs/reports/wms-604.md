## Review, исправления и рефакторинг

Разобраны исходные lifecycle/cutover/recovery/gateway scripts. Не переносили Helm upgrade
в управляемое Argo приложение. Общий thin image builder использует journal из фактического
base image и вычисляет следующую entry; applied SQL исходников не меняется. Выбор image
сохраняет baseline profile для rollback. Общий config binding verifier используется
целевым pull WMS-602 и GitOps registry prerequisite.

Первый release prototype дошёл до fresh Kafka tests и полного warehouse demo, затем
отказал при запуске load child: require с top-level await под --input-type=module дал
ERR_AMBIGUOUS_MODULE_SYNTAX. Воспроизведён фактический container program. Исправлены ESM
imports и немедленное распознавание child exit; regression запускает этот же program
и проверяет stop/no credential output. HTTP stub только обеспечивает transport contract;
реальный business load проверяет live release:drill. Таймауты/tests не ослаблялись.

Shared GitOps adapter changes требуют обоих live gates, включая restore/promotion;
native harness regression проверяет эту политику без возможности отключения через task.
Повторное review охватывает child completion/finally, ownership cleanup, секреты в argv/
logs/build layers, бинарный dump, exact data/schema/journal/sequences, runtime grants,
failed effects atomicity и судьбу внешних events. Повторный полный live run прошёл; финальный harness повторяет проверки на завершённом diff.

## Команды, evidence и ограничения

`pnpm release:drill` — фактическая новая репетиция. Safe summary:
artifacts/release-drill/evidence.json. Программа пишет started/finished times,
transportRecovery, business, rollingRelease, telemetry, rollback, forwardFix,
committedSchemaRepair, backupRecovery и cleanup. Private logs не являются public artifact.
Финальные harness:plan/run/ready выполняются по source task на завершённом diff;
runner JSON не переписывается вручную. Состояние running/failed не считается готовностью.

Backend/web unit coverage и CLI/native/Pod-program coverage — разные области.
Новые operational scripts не включены в Jest/Vitest baseline. API demo не является новым
browser/TLS proof. Thin images только локальные; production ingress, external Git auth,
private GHCR auth, HA, key escrow и production RPO/RTO не проверяются. Kind использует
PostgreSQL worker; отдельный Kafka drill проверяет политику transport recovery, не
atomic DB+Kafka restore. Все private keys/backup репетиции удаляются при cleanup.
