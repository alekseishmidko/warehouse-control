private kubeconfig/keys, whitelist Git и только synthetic DB. Реальные Git compare/sync,

production multi-tenant isolation. Public argocd-server/UI отсутствует.

## Review → исправления → повторное review

Argo не увеличивает Helm revision. Поэтому только opt-in mode использует фиксированное
имя Sync hook с BeforeHookCreation. Default pre-install/pre-upgrade/REV контракт сохранён.
Общий выбор pinned Helm binary переиспользован real render regression.

Прототип выявил отказ kind load docker-image: импорт multiarch index требовал отсутствующие
bytes другой platform. Docker index ID нельзя выдавать за config ID. Исправление:
selected-platform save → kind image-archive → существующий canonicalImage verifier;
archive config сверяется с CRI, runtime использует platform digest. Это не fallback
проверки identity. Повторный live gate с этим путём прошёл.

Убрана unused bad-credential Secret: отказ инъецируется реальным SQL. Общий SHA helper
переиспользует harness/snapshot; SOPS bootstrap/promotion используют одну encryption policy. Cleanup проверяет owned prefixes, освобождает private
files даже при отказе ownership, восстанавливает signal listeners. Native negative
regressions проверяют foreign tags/revision/checksum/URLs и cleanup. Source review
добавил comparison-ready предусловие и operation UUID, чтобы не принять старый sync.
Повторное review охватило новые/изменённые файлы и оба default/Argo render paths;
открытые эксплуатационные ограничения приведены ниже, искусственных findings нет.
