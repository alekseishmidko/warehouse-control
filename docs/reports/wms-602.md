## Review → fixes → regression → повторное review

1. Реальный первый scan выявил ошибочное сравнение OCI index inspect ID с Trivy
   config digest. ArchiveConfigId считает digest config bytes; negative tests проверяют
   ambiguity/path traversal и чужой image ID. Ошибка исправлена без снятия identity guard.
2. Review закрыл ambient TRIVY_* и checkout config overrides. Полный raw JSON сохраняется;
   scanner env/config не могут случайно скрыть advisory.
3. Новый Node24.22.3/Debian13 runtime содержит14 OS packages вместо88, без npm/Yarn/
   Corepack/shell. Policy вынесена из orchestration; runtime probes переиспользуются
   image-check и scanner. HIGH/CRITICAL после обновления —0; В первом release raw scan: LOW13/MEDIUM49/UNKNOWN3. Пять source rules настроены, но две OpenSSL advisory получили MEDIUM и не использовали waiver.

   недостижимость через текущий JS-only/ICU runtime, не исправление библиотек. Новые native

5. Source review разделило PR/read-only validation, package writer без checkout/rebuild
   и fresh target verifier с packages:read. Target helper отвергает tags/чужие refs,
   связывает requested digest через CRI и делает cleanup failure блокирующим.

   80f602502a5d0d4541da5e4839fe77a3a534d180 имеет тот же accepted tree

## Обнаруженный scan/export identity gap

В release44601420726 scan backend configId4f58b6c626fd05702552fbdd6072b729c9e8bd8ecd30a851c8ea0afa9477a7a5
не совпал с target CRI id7e795743511fdb457d723958e0d812b742608ba0c76b2bd9e7d3d89eb83d8619.
Причина: harness выполнял imageScan перед docker:gate; Docker gate строит тот же local
tag, а export после harness сохранял новый tag. Web config совпал. Все jobs были green,
но этого недостаточно для доказательства «опубликован scanned backend».
Исправление: docker до final scan, export config/tag guard и checked config binding
в target job. Нужен новый source commit и фактический release/pull. Предыдущие digests
и raw proof сохраняются как история, не accepted final evidence.

Review counters: старые manual13/47/5 не являются release facts. Реальный первоначальный
release scan13/49/3 подтверждён raw validation artifact. При попытке связать его с
целевым CRI обнаружен backend drift; первоначальный documentation harness остановлен
штатно, без изменения/ослабления tests. Final scan/export/config binding исправляется
в новом code snapshot, все gates и реальный release повторяются.
