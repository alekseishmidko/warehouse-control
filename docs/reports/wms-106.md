# WMS-106: запись в transactional outbox

Отчёт реализации 2026-10-22 для менеджера, разработчика и следующего агента.

## Результат

| Шаг | Реализовано |
|---|---|
| 106.1 | Новые migrations 0005/0006: events/deliveries/streams и transactional aggregate counter; PK/unique/FK/CHECK/indexes |
| 106.2 | OutboxService.append(context,AppendEventDto), private repository, borrowed client без собственного run/commit/pool |
| 106.3 | Writer-generated UUID, guarded counter upsert под row lock, безопасный bigint/number range и rollback версии |
| 106.4 | inventory.putaway зарегистрирован в коде/migration CHECK; pending delivery и stream cursor=0 в той же транзакции |
| 106.5 | Реальные PostgreSQL commit/rollback, uniqueness, race первого counter и ожидание lock с rollback/reuse |
| 106.6 | Immutable envelope grants/trigger; retention DELETE/TRUNCATE guards всех четырёх таблиц, без автоматического удаления |

Preflight фиксирует payload до первого await, затем окончательная версия снова
проходит EventContracts перед INSERT. JSONB сохраняет проверенный snapshot через
параметризованный cast; исходный input после await не сериализуется повторно.
Существующие stream cursor/lease не сбрасываются. Ошибку append нельзя подавлять:
она должна выйти до TransactionRunner и откатить весь сценарий.

Складской сценарий с InventoryService/movement/audit/outbox проверен integration,
но receiving document/HTTP ещё не реализованы. Writer не вызывает handler и не
подтверждает доставку. Повтор append — новый факт; redelivery должна читать старый event.

## Проверки

- `pnpm test`: 205 тестов (113 unit + 92 integration), 12 suites, реальные PostgreSQL Testcontainers/migrations.
- `pnpm typecheck`: production и test TypeScript без ошибок.
- Build и contracts:check выполнены test:prepare; schema annotations регенерированы contracts:generate.
- `pnpm db:generate` после новых migrations: no schema changes; прежние SQL не менялись.
- Migrations применены к чистой disposable БД и повторно: journal/data не меняются.
- После финального прогона нет контейнеров с label warehouse-controller.test=integration.
- Проверены относительные ссылки, каталог всех 15 новых файлов и git diff --check; старые SQL migrations не изменены.

Новая outbox suite содержит 36 тестов. В том числе: невидимость всех частей до commit,
rollback после writer со stock/audit, fault trigger при delivery INSERT после event/stream,
concurrent absent counter, фактический lock wait через pg_blocking_pids и независимый
агрегат, rollback всего batch с несколькими версиями, UUID case, version MAX/overflow,
рост финального message с 9→10 и rollback по byte limit, SQL PK/FK/CHECK и права.

Дополнительный crash-тест завершает transaction connection через pg_terminate_backend
до commit, проверяет отсутствие новых rows и успешный append с version=1 на новом
context/connection. Этот тест обнаружил необработанный error checked-out pg client
между запросами. Общая pool factory получила безопасный client error listener:
процесс не падает от EventEmitter error, а следующий query/commit по-прежнему
отвергает непригодное соединение. Драйверные детали не логируются, auto retry нет.
Полный набор потребителей adapter перепроверен после исправления.

## Ограничения

Worker/claim/leases/retry/dead handling, consumer markers/cursors и handler effects
не реализованы. Повторная доставка, конкуренция workers и восстановление после claim
не проверялись: это обязательные будущие integration tests WMS-109/110.
Crash-тест доказывает rollback **до commit**, не разрешает неизвестный исход при
потере ответа уже выполненного commit. Exactly once не обещается.

Runtime group warehouse_app — не production login; dev Compose остаётся admin.
DBA способен отключить triggers. Доверенный SQL adapter обязан соблюдать протокол;
constraints не повторяют всю JSON Schema и не доказывают истинность бизнес-факта.
Новые destinations требуют миграции и replay/стартовой позиции. Retention не включён,
disk usage будет расти; удалять историю вручную для освобождения места нельзя.

Dev Compose/volume не менялись и не мигрировались. После обновления dev-среды
нужно явно выполнить `pnpm db:migrate`. Native test:db-baseline не запускался:
он перезапускает dev volume и не нужен для disposable outbox проверки.
Kafka, backend Docker image и внешний стенд не подключались. Следующая задача — WMS-107.
